## 문제

[LeetCode 2124](https://leetcode.com/problems/check-if-all-as-appears-before-all-bs/): `a`와 `b`로만 이루어진 문자열 `s`에서 **모든 `a`가 모든 `b`보다 앞에 오면** `true`를 반환한다.

## 접근

- 모든 `a`가 모든 `b`보다 앞에 오려면, **마지막 `a`의 위치 < 첫 번째 `b`의 위치**이면 된다.
- `a`가 없거나 `b`가 없으면 비교할 필요 없이 `true`.
- `rfind`와 `find`로 각각 한 번씩만 훑으면 되므로 시간 복잡도는 O(n)이다.

## 제출 코드

```python
class Solution:
    def checkString(self, s: str) -> bool:
        last_a = s.rfind('a')
        first_b = s.find('b')

        # If there is no 'a' or no 'b' -> true
        if last_a == -1 or first_b == -1:
            return True

        # if a[rightest] < b[leftest] -> true
        return last_a < first_b
```
