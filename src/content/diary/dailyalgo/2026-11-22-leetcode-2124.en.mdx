## Problem

[LeetCode 2124](https://leetcode.com/problems/check-if-all-as-appears-before-all-bs/): Given a string `s` consisting only of `a` and `b`, return `true` if **every `a` appears before every `b`**.

## Approach

- Every `a` comes before every `b` exactly when the **position of the last `a` < the position of the first `b`**.
- If there is no `a` or no `b`, there is nothing to compare, so return `true`.
- `rfind` and `find` each scan the string once, so the time complexity is O(n).

## Submitted Code

```python
class Solution:
    def checkString(self, s: str) -> bool:
        last_a = s.rfind('a')
        first_b = s.find('b')

        # If there is no 'a' or no 'b' -> true
        if last_a == -1 or first_b == -1:
            return True

        # if a[rightest] < b[leftest] -> true
        return last_a < first_b
```
